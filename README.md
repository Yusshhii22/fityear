# FitYear 💪

**Your automated 1-year fitness journey** — a free, offline-capable web app that turns a 2-minute questionnaire into a complete 52-week plan: progressive workouts, gram-level meal plans, grocery lists, and adaptive coaching.

**▶ Use it now: https://yusshhii22.github.io/fityear/**

## Install on your phone

1. Open the link above in Chrome (Android) or Safari (iPhone)
2. Android: tap **⋮ → Add to Home screen** · iPhone: tap **Share → Add to Home Screen**
3. It installs like a native app and works fully offline

## Features

- **Step-by-step onboarding** — a one-question-per-screen wizard that ends with a personalized plan preview
- **Trainer or self-guided** — trainers set up the plan for a client (all questions ask about the client) and can reorder days & exercises and edit sets/reps/rest per week; everyone else gets plain-English coaching
- **52-week periodized program** — Foundation → Build → Strength → Peak phases with deload weeks, matched to your training style (bodyweight / home / gym / calisthenics / CrossFit-style / yoga & pilates) and 2–6 training days per week
- **Targeted cool-downs** — every workout ends with stretches matched to the muscle groups trained that day
- **Supplement guidance** — a stack personalized to your goal and diet with doses and best timing: daily checklist on Today, full why-and-how guide in Plan
- **Built-in app tutorial** — a first-run guided tour plus a replayable ❓ help guide
- **Exercise tutorials** — tap any exercise for step-by-step instructions with animated demo photos (courtesy of the public-domain [free-exercise-db](https://github.com/yuhonas/free-exercise-db)) and video links
- **Meals with gram portions** — 60 Indian-friendly meals (veg / non-veg / vegan) computed from an ingredient database and scaled to your calorie & protein targets
- **Weekly grocery lists** — checkable in-app and printable
- **Voice set logging** — tap 🎤 and say "3 sets of 10 at 45 kg"
- **Adaptive coaching** — weekly weigh-ins auto-tune your calorie target with plain-English coach notes
- **Progress analytics** — weight trend and per-exercise strength charts (estimated 1RM)
- **Gamified** — XP, levels, streaks, badges
- **Printable week sheets** — take a paper plan to the gym
- **Private by design** — all data stays on your device; JSON backup/restore included

## Tech

Vanilla HTML/CSS/JS, no build step, no dependencies. PWA with a service worker for offline use. Hosted on GitHub Pages.
